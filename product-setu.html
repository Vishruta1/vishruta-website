SETU : SECURED UNIFIED TRACKING PORTAL

Software platform for secure monitoring, OTP-based control, email alerts and real-time activity logging.

OBJECTIVE

To provide secure, real-time monitoring of desktop activity with OTP-based control and email alerts, ensuring restricted access, tamper-proof supervision, and audit-ready logs.

Platform Overview

ENGINEERED FOR UNCOMPROMISED INDUSTRIAL SECURITY

SETU delivers tamper-proof supervision and operational security tailored for manufacturing lines and engineering offices.

Secure & Reliable

Ensures restricted access and tamper-proof monitoring across plant workstations, preventing unauthorized software interference.

Real-time Visibility

Monitor operator activities in real time and receive instant encrypted notifications upon any supervisor pause or override.

Workflow Architecture

HOW SETU WORKS

A rigorous 6-stage authorization sequence that prevents unmonitored plant downtime and records every action.

1. Monitoring in Progress
Target UI elements & buttons blocked
➔
2. User Initiates Stop
Prompts Admin / Supervision Mode
➔
3. System Generates OTP
Dynamic QR Code / Security Code
➔
4. Authorized User Enters OTP
Validates Employee ID & Credentials
➔
5. Monitoring Stops & Log Saved
Tamper-proof audit record stamped
➔
6. Email Alert Sent Instantly
Registered recipients notified
Platform Highlights

KEY FEATURES

Prevent Unauthorized Usage

Blocks specific UI elements or actions based on pre-configured images or buttons, preventing accidental line stoppages or unauthorized configuration changes.

OTP-based Supervision Control

Generates and verifies one-time passwords before allowing monitoring to pause or stop, enforcing an unbreakable two-person rule on sensitive lines.

Email Notifications for Every Event

Sends OTP, employee info, timestamp, and stated reason to registered management recipients instantly via encrypted SMTP.

Real-time Activity Logging

Local encrypted log file records all OTP attempts and monitoring actions; easily filtered by Date & Employee ID and exportable directly to Excel.
